Entry for the make.fun bounty
[**The Internet in One Word**](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b):
sum up the whole internet in a single word — and make it funny.

`main.py` (Python 3.13, pure standard library) writes one word to
`/output/entry.txt`: **feral**.

Why *feral*? The internet is wild, untamed, and occasionally bites —
one word, five letters, one beat, and it lands the joke about the whole
internet at once. It beat nine other candidates (unhinged, tabs, void,
screaming, loud, abyss, rabbithole, doomscroll, sidequest) judged against
the brief: funny first, true of the internet as a whole, surprising.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.txt (5 bytes, no newline)
```
